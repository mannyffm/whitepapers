# Hoom: A Trust-First House Sitting Platform

# Executive Summary

House sitting creates enormous value for homeowners and sitters, but current platforms often create friction through poor verification, weak reporting mechanisms, unclear listings, and a homeowner-first design philosophy.

Hoom proposes a trust-first marketplace designed from the sitter and homeowner experience outward.

# The Problem

## Current State

House sitting platforms connect thousands of homeowners and sitters globally.

## Key Issues

1. Listing accuracy
2. Weak reporting workflows
3. Poor handling of rule violations
4. Trust asymmetry between sitters and homeowners
5. Platform complexity and user friction
